## 主要人物视觉设定

### 鲧（禹之父，治水失败者）

- **五官**：中年男子，方脸阔额，额头饱满，剑眉入鬓，眼窝微陷、目光坚毅而温和，鼻梁高挺，嘴唇厚实，颏下一部黑色长须，山羊胡微微上翘；肤色为饱经风霜的小麦色。
- **身材**：高大魁梧，肩背宽阔厚实，肌肉结实，赤足站立，左脚在前呈行走姿态。
- **衣着**：头戴竹编尖顶斗笠，身穿浅蓝色交领右衽广袖长袍，肩披棕黄色动物皮毛披肩，腰系朱红色宽腰带，手持木质耒耜（翻土农具）。

### 禹（大禹，治水成功者）

- **五官**：长圆脸，额头宽广微秃、发际线后移，眉毛疏淡细长，眼睛细长微眯、眼尾下垂，目光平和威严；鼻梁挺直，嘴唇薄而紧闭，颏下蓄稀疏修长灰黑色长须；肤色白皙偏黄，神态沉稳安详，不怒自威。
- **身材**：肩背挺拔端正，身形清瘦修长，肩窄而平，呈儒雅文臣气质。
- **衣着**：头戴青玉（绿松石色）扁平梁冠，冠正面镶嵌大块翠绿宝玉；内穿月白浅灰交领衬袍，外罩玄黑深褐黑交领右衽宽袖长袍，胸前垂两条蓝色长系带，衣缘简约无繁杂花纹。

## 史料背景（简要）

- **《史记·五帝本纪》**（卷一）：记录上古传说时代五位部落联盟首领（黄帝、颛顼、帝喾、尧、舜），其中记载了洪水泛滥、鲧治水失败，为大禹治水故事铺垫背景。
- **《史记·夏本纪》**（卷二）：紧接《五帝本纪》，全文重点篇幅写大禹。尧时洪水滔天，鲧筑坝挡水九年不成；舜杀鲧，举荐禹继续治水。禹吸取教训，采用疏导法疏通河道，十三年治水，三过家门而不入，划定九州，平定水患。舜禅位于禹，建立夏朝；禹之后传位给儿子启，禅让制变为世袭制，开启中国第一个王朝。

两篇前后相连，共同构成《大禹治水》的原始史料。

## 中心思想

课文通过讲述大禹治水的故事，歌颂了大禹 **无私奉献、一心为民、科学治水、坚持不懈** 的高尚品质。大禹为了治理洪水，十三年奔波在外，三过家门而不入，最终用疏导法治服洪水，使百姓安居乐业。故事告诉我们：**做事情要善于总结经验教训，采用科学的方法，持之以恒，才能取得成功**。

同时，大禹治水是中华民族从远古走向文明的重要传说，体现了上古先民 **不畏艰险、勇于抗争、以民为本** 的精神，也是"华夏子孙"认同大禹为人文始祖之一的重要原因。

## 课文解析

### 词语解析

- **泛滥**：江河湖泊的水溢出，四处流淌。形容洪水范围广、来势猛。
- **牲畜**：人类饲养的家畜（如牛、羊、猪、狗等），文中泛指百姓赖以生存的全部家畜。
- **筑坝挡水**：鲧治水的方法——修筑堤坝拦截洪水。这是"堵"的思路，治标不治本。
- **疏导**：禹治水的方法——疏通河道，让洪水顺着河道流走。这是"疏"的思路，从根本上解决问题。
- **三过家门而不入**：出自《史记·夏本纪》，原指大禹治水三次路过家门都没进去。形容因公忘私、全心全意投入工作的精神。
- **安居乐业**：安定地生活，愉快地劳动。形容百姓过上了安稳幸福的日子。

### 关键句解析

1. **"曾经多次路过自己家门口。可是他认为治水要紧，一次也没有走进家门看一看。"**  
   用"多次路过"与"一次也没有走进"的对比，突出大禹治水的决心和无私。不是不想家，而是把百姓的安危放在第一位。

2. **"禹吸取了鲧治水失败的教训，采用疏导的办法治水。"**  
   这是禹治水成功的关键转折。从父亲的失败中汲取教训，说明禹善于思考、不盲从。"堵"与"疏"一字之差，体现了两种截然不同的治水理念。

3. **"洪水终于退了……百姓安家乐业，重新过上了幸福的生活。"**  
   用"终于"呼应治水的艰难（十三年），用"安居乐业、幸福"与开篇的"痛苦极了"形成鲜明对比，首尾呼应，突出大禹治水的功绩。

### 写作手法

- **首尾呼应**：开头写洪水泛滥、百姓痛苦；结尾写洪水退去、百姓幸福，形成强烈对比。
- **对比衬托**：鲧的"筑坝挡水"与禹的"疏导治水"形成对比，突出禹治水方法的科学；大禹"多次路过家门"却"一次也没进"，衬托出他的无私。
- **数字叙事**："九年"（鲧治水）、"十三年"（禹治水），用具体数字说明治水时间长、任务艰巨。
